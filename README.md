On a Mac, open the DMG and drag Autopen MoJo Active to Applications. On Windows, run the installer; it installs for your account only and needs no administrator rights.

Autopen MoJo Active updates itself. It checks for new versions when it starts and every few hours, downloads them in the background, and installs them when it restarts.
